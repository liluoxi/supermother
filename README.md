# supermother

`index.html` 是完整的单页母亲节礼物网站，适合直接部署到 GitHub Pages。

## 使用方式

1. 打开站点后先在“爱的编辑台”上传图片、视频、语音并填写文字。
2. 点击“应用到页面”预览效果。
3. 点击“生成新 URL 和二维码”得到分享链接。
4. 将仓库主分支发布到 GitHub Pages 后，扫码即可打开这个礼物页面。

## GitHub Pages 部署

1. 推送代码到 GitHub 主分支。
2. 在仓库 `Settings > Pages` 中，选择 `Deploy from a branch`。
3. 选择 `main` 分支和 `/root` 目录。
4. 保存后等待 GitHub 生成站点地址。

## 说明

- 这是纯静态前端方案，不依赖后端服务。
- 文本和愿望会保存到浏览器本地。
- “发布”功能会把当前配置编码进链接中，因此上传素材越大，生成的 URL 就越长。
- 如果分享链接过长，请压缩素材后再发布。
